## Requirements

<ol> 
    <li>Create a representation for the chessboard.</li>
    <li>Represent all the pieces: King, Queen, Bishop, Knight, Rook, and Pawn.</li>
    <li>Differentiate the pieces based on color: Black and White.</li>
    <li>Each piece should have a method to determine its legal moves based on its current position.</li>
    <li>The chessboard should have a method to move a piece from one position to another.</li>
    <li>There should be a way to check the status of the game, e.g., ongoing, check, checkmate, or stalemate.</li>
    <li>The game should support special moves: castling, pawn promotion, and en passant.</li>
    <li>Implement a player class, where each player has a color and a set of pieces.</li>
    <li>Include a game class that will handle turn-based gameplay between two players.</li>
    <li>The game should have a method to capture and remove a piece from the board.</li>
</ol>
